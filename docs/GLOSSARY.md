# Glosarium

> **Status: DRAFT — BELUM FINAL — BELUM DISETUJUI.**

| Istilah | Arti |
|---|---|
| E2EE | End-to-End Encryption; pesan dienkripsi pada pengirim dan didekripsi pada penerima |
| Identity | Identitas kriptografis lokal PAIRO |
| Pairing | Hubungan komunikasi yang disetujui dua identity |
| Fingerprint / Safety Number | Representasi ringkas material identity untuk diverifikasi |
| WebRTC | Teknologi komunikasi real-time; DataChannel dapat membawa data peer-to-peer |
| Signaling | Pertukaran informasi untuk membangun koneksi WebRTC |
| STUN | Mekanisme untuk membantu endpoint mengetahui alamat/jalur jaringan |
| TURN | Relay trafik real-time ketika koneksi langsung gagal |
| Store-and-forward | Penitipan pesan terenkripsi sementara sampai penerima mengambilnya |
| Ciphertext | Data terenkripsi yang tidak dapat dibaca tanpa key yang sesuai |
| TTL | Time To Live; batas waktu data tersedia |
| ACK | Acknowledgment; konfirmasi penerimaan pesan |
| Local-first | Data utama berada di perangkat pengguna |
| Recovery secret | Rahasia untuk memulihkan backup atau identity |
| Metadata | Informasi tentang komunikasi, misalnya waktu, ukuran paket, atau IP |
| Mutual consent | Persetujuan dari kedua pihak sebelum pairing aktif |
