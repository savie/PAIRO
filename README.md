# PAIRO

**Two Identities. One Private Space.**

PAIRO adalah konsep messenger Android untuk komunikasi privat dua identity dengan E2EE, penyimpanan lokal, dan backup cloud pribadi yang opsional digunakan.

## Prinsip
- Riwayat chat disimpan lokal.
- Tidak ada cloud database untuk chat history permanen.
- Backup terenkripsi tersedia melalui cloud milik pengguna.
- Offline delivery memakai temporary ciphertext relay, retensi maksimal tujuh hari.
- Identity dan pairing terisolasi.
- Developer tidak memiliki master key untuk membaca percakapan.

**Status:** tahap perencanaan; belum ada implementasi aplikasi Android.
